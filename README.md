# 🎓 Find University

**Find University** is a simple and interactive web application that allows users to search for universities by entering a country name. The app uses the [Hipolabs Universities API](http://universities.hipolabs.com/) to fetch and display university names in a clean, responsive interface.

---

## 🚀 Live Demo

👉 [View on GitHub Pages](https://dnyanesh3256.github.io/FindUniversityProject/)

---

## 🌟 Features

- 🔍 Search universities by country name  
- ⚡ Fetch data dynamically using Axios (async/await)  
- 📋 Display results in a user-friendly list  
- 🎨 Modern, responsive, and interactive UI  

---

## 🚀 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Axios** for API requests
